Privacy Policy for Aero

Last updated: November 3, 2026

Aero (“the app”) is a REST API client for macOS. Your privacy matters, and this policy explains how the app handles your data.

Data Collection

Aero does not collect, store, or transmit any personal data to the developer or any third party. The app has no analytics, no tracking, and no user accounts.

Your Data Stays on Your Device

All data you create in Aero — including requests, collections, environments, variables, and request history — is stored locally on your Mac. It is never uploaded to any server controlled by the developer.

Network Requests

Aero is an API client. When you send a request, the app connects directly to the server address (URL) that you enter. Any data you include in those requests — such as headers, authentication tokens, or request bodies — is sent only to that destination, exactly as you specify. The developer has no access to this traffic.

Third-Party Services

Aero does not integrate any third-party analytics, advertising, or data-collection SDKs.
